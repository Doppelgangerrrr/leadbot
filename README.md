# LeadBot: Telegram-бот приёма заявок

Бот для малого бизнеса (сервис, студия, мастерская): клиенты оставляют заявки, администраторы получают их с кнопками статусов, клиент видит, как продвигается его заявка.

Демо настроено под мастерскую по ремонту техники. Под другой бизнес бот перенастраивается правкой одного файла `bot/texts.py`.

## Возможности

**Для клиента**
- пошаговая анкета: услуга → имя → телефон (кнопкой «Отправить мой номер» или вручную) → комментарий → подтверждение;
- проверка и нормализация телефона (`8 900 123-45-67` → `+79001234567`);
- «Мои заявки» со статусами;
- прайс-лист и информация о компании;
- уведомление, когда администратор меняет статус заявки.

**Для администратора**
- карточка каждой новой заявки в личку или в общую группу;
- смена статуса одной кнопкой: 🆕 Новая / 🔧 В работе / ✅ Выполнена / 🚫 Отклонена;
- `/stats`: статистика (всего, за сегодня, по статусам, число пользователей);
- `/export`: выгрузка всех заявок в CSV, который сразу открывается в Excel;
- `/broadcast`: рассылка всем пользователям с предпросмотром и учётом лимитов Telegram.

## Стек

Python 3.11+, [aiogram 3](https://docs.aiogram.dev/) (asyncio), SQLite через `aiosqlite`, FSM для анкет, конфиг через `.env`.

## Запуск

```bash
python -m venv .venv
.venv\Scripts\activate          # Windows; на Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
copy .env.example .env          # Linux/macOS: cp .env.example .env
```

Заполните `.env`:
- `BOT_TOKEN`: токен от [@BotFather](https://t.me/BotFather);
- `ADMIN_IDS`: ваш Telegram id (узнать можно у [@userinfobot](https://t.me/userinfobot));
- `ADMIN_CHAT_ID` (необязательно): id группы для заявок. Добавьте бота в группу, а администраторов укажите в `ADMIN_IDS`: менять статусы могут только они.

Запустите:

```bash
python -m bot
```

## Структура

```
bot/
├── __main__.py      # точка входа, сборка Bot и Dispatcher
├── config.py        # настройки из .env
├── db.py            # работа с SQLite: пользователи, заявки, статистика
├── texts.py         # все тексты, услуги и статусы (меняется под клиента)
├── keyboards.py     # reply- и inline-клавиатуры
├── states.py        # состояния FSM: анкета, рассылка
├── notify.py        # уведомления администраторам
└── handlers/
    ├── user.py      # клиентская часть
    └── admin.py     # админ-панель, статусы, экспорт, рассылка
```
